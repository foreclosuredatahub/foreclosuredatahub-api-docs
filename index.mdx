## Overview

The API uses HTTPS, JSON responses, and an `x-api-key` header. Retail API access is available on eligible Pro and Business subscriptions; Starter does not include API access. Commercial licenses use separate keys and allowances.

## Authentication

Generate a key in [API settings](https://www.foreclosuredatahub.com/dashboard/api), then follow the [authentication guide](/authentication).

## Rate limits

Review [rate limits and row allowances](/concepts/rate-limits) before sending requests. API property responses share retail row allowances with CSV and Google Sheets exports.

## Response format

Keep each listing's `source` and `row_id` for reconciliation. See the [response field guide](/concepts/responses).
