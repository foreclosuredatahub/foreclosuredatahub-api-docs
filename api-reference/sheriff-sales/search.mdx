Sheriff Sales returns qualified sheriff-administered mortgage sale listings, preserving authority and legal basis. Customer-facing scheduled statuses are returned as Scheduled. Owner, valuation and generic sale-status filters are unsupported.

Results are normalized automatically in `data.records`. No `mode=unified` or location filter is required. Each returned row consumes the applicable delivered-row allowance.

## Parameters

Unknown parameters and repeated scalar parameters return `400`. Date and numeric ranges must run from lower to higher values.

| Parameter | Meaning |
| --- | --- |
| `state` | US state name or abbreviation. Repeat for multiple values, at most 50. |
| `county` | Partial county name. Repeat for multiple values, at most 50. |
| `zip` | Property ZIP prefix. Repeat for multiple values, at most 50. |
| `address` | Partial property address. Repeat for multiple values, at most 50. |
| `sale_date_start` | Inclusive sale date start, YYYY-MM-DD. |
| `sale_date_end` | Inclusive sale date end, YYYY-MM-DD. |
| `sale_days` | Minimum sale lead time, 1 to 365 days. Tax sales require a known date and use local sale days. Trustee and sheriff searches retain undated rows unless another date filter excludes them. |
| `q` | Search parcel, case, writ, or auction identifiers. |
| `page` | Page number, starting at 1. Keep page_size fixed while paging. |
| `page_size` | Rows per page: 1 to 100 paid, 1 to 10 trial. Defaults to 25 paid or 10 trial. An omitted first-page size may shrink to the remaining allowance. |
| `limit` | Alias for page_size; values must match when both are supplied. |

## Examples

<CodeGroup>

```bash cURL
curl --fail-with-body -H "x-api-key: $FDH_API_KEY" \
  "https://www.foreclosuredatahub.com/api/v1/sheriff-sales/search?state=PA&county=Philadelphia&page_size=5"
```

```javascript JavaScript
const response = await fetch(
  "https://www.foreclosuredatahub.com/api/v1/sheriff-sales/search?state=PA&county=Philadelphia&page_size=5",
  { headers: { "x-api-key": process.env.FDH_API_KEY } }
);
if (!response.ok) throw new Error(`API request failed: ${response.status}`);
const result = await response.json();
```

```python Python
import os
import requests

response = requests.get(
    "https://www.foreclosuredatahub.com/api/v1/sheriff-sales/search?state=PA&county=Philadelphia&page_size=5",
    headers={"x-api-key": os.environ["FDH_API_KEY"]},
    timeout=60,
)
response.raise_for_status()
result = response.json()
```

## Response

The OpenAPI response panel includes a synthetic record example and an empty result. Example identities and property details are illustrative.

A query can succeed with no matching records. This valid empty example does not indicate unavailable inventory:

```json
{
  "data": {
    "records": []
  },
  "meta": {
    "category": "sheriff-sales",
    "unit": "sale_listings",
    "total": 0,
    "page": 1,
    "per_page": 5,
    "total_pages": 0
  }
}
```

Records follow the `SheriffSale` schema in the OpenAPI reference. Retain `source` and `row_id` for reconciliation. Use [matching counts](/api-reference/sheriff-sales/counts) to check result size. Inventory can change between requests. When the reader reports unavailable data, the API returns `503` instead of a successful empty result.
