---
title: "List sources"
description: "Discover available feeds, coverage, and supported filters."
openapi: "GET /api/v1/sources"
---

List all available data sources with their coverage and supported filters. coverage is one of national (all US states), regional (a subset of states), state (one state), or county (one county). states lists the USPS codes covered; it is null for national feeds and for regional feeds whose footprint varies - query /v1/properties/data with the state filter to enumerate those.

## Parameters

| Parameter | Meaning |
| --- | --- |
| `category` | Optional: `trustee-sales`, `sheriff-sales`, `tax-sales`, `tax-delinquent`, or `filings`. Omit for the original property feed catalog. |

When using `category`, supply it once and do not add other parameters. The response remains a `data` array. Category entries add `category`, `coverage_basis`, and supported filter names. Some include county metadata or source dates.

- `configured`: The source/category is configured for these states or counties. This does not promise current inventory or complete coverage.
- `published`: Delinquency source metadata, including `available` and source/capture/expiry dates when supplied.
- `current_inventory`: Filing sources represented by currently eligible property records.

Tax and sheriff sales each expose an aggregate inventory ID (`tax_sales` and `sheriff_sales`). Trustee feeds retain their numbered IDs. Delinquency and filings use their source keys. These category IDs do not expand the legacy `/properties/data` source catalog.

```bash
curl --fail-with-body -H "x-api-key: $FDH_API_KEY" \
  "https://www.foreclosuredatahub.com/api/v1/sources?category=tax-sales"
```

See [category semantics](/guides/foreclosure-categories) before interpreting coverage or totals.

## Examples

<CodeGroup>

```bash cURL
curl -H "x-api-key: fdh_ak_your_key_here" \
  https://www.foreclosuredatahub.com/api/v1/sources
```

```javascript JavaScript
const res = await fetch(
  "https://www.foreclosuredatahub.com/api/v1/sources",
  { headers: { "x-api-key": "fdh_ak_your_key_here" } }
);
const data = await res.json();
```

```python Python
import requests

res = requests.get(
    "https://www.foreclosuredatahub.com/api/v1/sources",
    headers={"x-api-key": "fdh_ak_your_key_here"}
)
data = res.json()
```

</CodeGroup>

## Response shape

Illustrative response; `...` represents omitted fields or records.

```json
{
  "data": [
    {
      "id": "feed-01",
      "name": "Data Feed 01",
      "coverage": "regional",
      "states": ["AL", "AZ", "CA", "..."],
      "filters": { "county": true, "state": true, "sale_date": true, "owner_name": true, "est_value": true }
    },
    ...
  ]
}
```
