Early Filings returns eligible matched properties grouped by proceeding and parcel. It includes recording dates, document references, classifications and recorded parties. state filters filing jurisdiction; situs_state describes the matched property. Internal review and unresolved-match data are excluded.

Results are normalized automatically in `data.records`. No `mode=unified` or location filter is required. Each returned row consumes the applicable delivered-row allowance.

## Parameters

Unknown parameters and repeated scalar parameters return `400`. Date and numeric ranges must run from lower to higher values.

| Parameter | Meaning |
| --- | --- |
| `state` | Filing jurisdiction as a US state name or abbreviation. |
| `county` | Partial county name or qualified county key such as FL:Duval. |
| `source` | Filing source ID from /sources?category=filings. |
| `q` | Search instrument, case, address, legal text, and recorded parties. |
| `recorded_from` | Inclusive recording date start, YYYY-MM-DD. |
| `recorded_to` | Inclusive recording date end, YYYY-MM-DD. |
| `event_type` | Recorded event type; results remain eligible property groups. |
| `filing_kind` | Filing classification; a candidate does not establish a completed foreclosure. |
| `has_case` | Require a reported case number. |
| `page` | Page number, starting at 1. Keep page_size fixed while paging. |
| `page_size` | Rows per page: 1 to 100 paid, 1 to 10 trial. Defaults to 25 paid or 10 trial. An omitted first-page size may shrink to the remaining allowance. |
| `limit` | Alias for page_size; values must match when both are supplied. |

## Examples

<CodeGroup>

```bash cURL
curl --fail-with-body -H "x-api-key: $FDH_API_KEY" \
  "https://www.foreclosuredatahub.com/api/v1/filings/search?state=FL&recorded_from=2026-10-01&page_size=5"
```

```javascript JavaScript
const response = await fetch(
  "https://www.foreclosuredatahub.com/api/v1/filings/search?state=FL&recorded_from=2026-10-01&page_size=5",
  { headers: { "x-api-key": process.env.FDH_API_KEY } }
);
if (!response.ok) throw new Error(`API request failed: ${response.status}`);
const result = await response.json();
```

```python Python
import os
import requests

response = requests.get(
    "https://www.foreclosuredatahub.com/api/v1/filings/search?state=FL&recorded_from=2026-10-01&page_size=5",
    headers={"x-api-key": os.environ["FDH_API_KEY"]},
    timeout=60,
)
response.raise_for_status()
result = response.json()
```

</CodeGroup>

## Response

The OpenAPI response panel includes a synthetic record example and an empty result. Example identities and property details are illustrative.

A query can succeed with no matching records. This valid empty example does not indicate unavailable inventory:

```json
{
  "data": {
    "records": []
  },
  "meta": {
    "category": "filings",
    "unit": "proceeding_parcels",
    "total": 0,
    "page": 1,
    "per_page": 5,
    "total_pages": 0
  }
}
```

Records follow the `FilingProperty` schema in the OpenAPI reference. Retain `source` and `row_id` for reconciliation. Use [matching counts](/api-reference/filings/counts) to check result size. Inventory can change between requests. When the reader reports unavailable data, the API returns `503` instead of a successful empty result.
