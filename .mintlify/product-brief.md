# Product brief

## Description
Foreclosure Data Hub provides API access to property feeds, trustee and sheriff sales, tax sales, tax delinquency, and early filing records.

## Primary audience
Developers integrating these records into internal research tools or licensed customer-facing products. This audience is inferred from the existing quickstart and licensing pages.

## Jobs to be done
Obtain an API key, choose the relevant category and coverage, retrieve bounded pages, reconcile records, and handle quotas and unavailable data.

## Motivation
Offer a consistent API over heterogeneous published records while preserving category-specific identities, dates, statuses, and counting units. Coverage varies by source and county; the documentation must not imply universal inventory.
